# Programación en Java – Fundamentos de Programación y ADDA

Este repositorio reúne los ejercicios, prácticas y proyectos desarrollados en Java durante las asignaturas de **Fundamentos de Programación** y **Análisis y Diseño de Datos y Algoritmos (ADDA)** del Grado en Ingeniería Informática.

En la asignatura de Fundamentos de Programación se trabajaron los conceptos esenciales de la programación, aprendiendo a desarrollar programas desde cero y a resolver problemas mediante el uso de estructuras de control, métodos, arrays y otros elementos fundamentales del lenguaje Java. También se trabajó con la programación orientada a objetos, utilizando clases, objetos, atributos y métodos para organizar y estructurar el código.

Por otro lado, en ADDA se profundizó en el diseño y desarrollo de algoritmos, la organización y manipulación de datos y la resolución de problemas de mayor complejidad. Se aplicaron diferentes técnicas de programación para implementar soluciones, analizar su funcionamiento y estudiar su eficiencia.

El propósito de este repositorio es centralizar el trabajo realizado en ambas asignaturas y reflejar la evolución de los conocimientos adquiridos en Java, desde los fundamentos de la programación hasta la aplicación de estructuras de datos y técnicas algorítmicas para desarrollar soluciones a distintos problemas.
